# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- Run: `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` (in-memory H2) or `docker compose up -d db && ./mvnw spring-boot:run` (PostgreSQL); http://localhost:8080.
- Test: `./mvnw test` (Java, 25) and `npm test` (Jest, 45). Run both and report both counts before saying you are done.
- Single test: `./mvnw test -Dtest=ClassName#method`, `npx jest path/to/file.test.js -t "name"`.
- Backend: Spring Boot in `src/main/java/com/marlowefinch/ops/`; controllers → `DateRange` → repositories with plain SQL (Spring JDBC, no JPA); read-only JSON under `/api`.
- Frontend: plain JS/HTML/CSS in `src/main/resources/static/`, no framework or build; all logic in `initApp(document, fetchImpl)` in `app.js`.
- Data: Flyway migrations in `db/migration/`; seed is generated by `tools/make_seed.py`, never hand-edited.
- "Today" is pinned to 2026-09-21 (`ops.today`, `ClockConfig`); never use the real date.
- Jest tests use the fake API in `src/test/javascript/setup/loadApp.js`; register every new element id in its `REGISTERED_IDS`.
- No new dependencies (npm or Maven) unless asked.
- pom.xml dependencies are frozen. Any change needs a CHG ticket.
